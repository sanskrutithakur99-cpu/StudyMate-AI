🎓 StudyMate AI

An AI-powered study assistant designed to help students organize their learning, manage study tasks, and improve productivity.

✨ Features

- User Authentication – Register and login functionality.
- AI Chat – Ask study-related questions.
- Smart Notes – Create, save, edit and delete study notes.
- AI Note Summarization – Generate summaries of study notes.
- AI Quiz – Generate quizzes based on selected topics.
- Flashcards – Create, flip, delete and save flashcards.
- Study Planner – Organize study tasks and track completion.
- Progress Tracker – Monitor completed and pending tasks.

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript
Backend: Python, Flask
Database: SQLite
AI Integration: Google Gemini API
Tools: VS Code, Git, GitHub

🚀 Getting Started

1. Clone the repository:

git clone https://github.com/sanskrutithakur99-cpu/StudyMate-AI.git

2. Install backend dependencies:

cd StudyMate-AI/backend
pip install -r requirements.txt

3. Create a ".env" file inside the backend folder:

SECRET_KEY=your-secret-key
GEMINI_API_KEY=your-gemini-api-key

4. Start the Flask backend:

python app.py

5. Open the frontend using VS Code Live Server.

🔐 Security

API keys and environment variables are stored locally and excluded from version control using ".gitignore".
